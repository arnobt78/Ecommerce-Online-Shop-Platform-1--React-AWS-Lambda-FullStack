# cycles/

Frozen, read-only archives of completed cycles (`C1/`, `C2/`, ...) — a snapshot of that cycle's `.agile-v/*.md` state at close, per `agile-v-lifecycle`. C1 is currently **active**; its living state is the top-level files in `.agile-v/`, not this directory. `cycles/C1/` will be populated only when C1 closes and C2 begins.
